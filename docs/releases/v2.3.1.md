## Fixed
- **Google Drive: files showed no folder / looked misplaced.** After you renamed the Drive folder, the file list showed "—" as the folder and your backups seemed to have vanished. In fact they were still in the old folder — only the view was wrong.

Now the Cloud page shows each file's real folder in Drive (for example `NCM-Backups/KODAKARA`), marks any file that is in an older folder rather than the one you have configured now, and makes clear that renaming the Drive folder only changes where **new** backups go — it does not move or rename files already in Drive.
