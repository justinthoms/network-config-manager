## Fixed
- **NCM 2.1.0 did not start on Windows.** The in-app updater used a Linux-only file lock; on Windows it now uses the Windows one. Linux and macOS installs are not affected, but get the fix as well.

## How to upgrade
- **From 2.1.0 (Linux):** open **user menu → Updates** and click **Upgrade to 2.1.1**. Your settings, database and backups are kept.
- **From 2.1.0 on Windows, or from 2.0.0:** upgrade by hand once: `git fetch --tags && git checkout v2.1.1`, then `pip install -r backend/requirements.txt` and restart NCM. Later versions can be installed from the Updates page.
