## Highlights

### 📊 Anonymous usage reporting
NCM can now tell its author how many installs there are and which version they run. Once a day it sends a small heartbeat containing **only** the project name, the version, the server hostname and a random install id.

It never sends IP addresses, device data, backups, user data or any credential — the **Security** page shows the exact payload, live, and a Super Admin can turn it off with one switch (or `TELEMETRY_ENABLED=false` in `backend/.env`). On by default; point `TELEMETRY_URL` at your own collector to keep the data in-house.

## Upgrade
From 2.1.x on Linux: **user menu → Updates → Upgrade to 2.2.0**. Your settings, database and backups are kept. The full list of changes is in [CHANGELOG.md](https://github.com/justinthoms/network-config-manager/blob/main/CHANGELOG.md).
