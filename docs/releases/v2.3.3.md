## Fixed
- **Google Drive: one NCM install showed another install's backups.** When two NCM servers were connected to the **same Google account**, each one's "Files in Google Drive" list showed the other's backups too — because NCM's Drive scope can see every file its app created in the account.

The list is now **scoped to the Drive folder configured on that server**, so each install shows only its own backups. The 2.3.2 "move into this folder" button has been removed, since with a shared account it could have moved another install's files into the wrong folder.

**If you run several NCM servers on one Google account:** give each a different **Drive folder name** on the Cloud page (e.g. `NCM-TSR-DIS`, `NCM-WEONE`). Backups already uploaded stay where they are; you can open the old folder from Drive.
