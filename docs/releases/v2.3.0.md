## Highlights

### 🔵 Cisco support
Cisco IOS / IOS-XE is now a supported vendor, alongside Huawei, Juniper and Arista. NCM backs up the running configuration, runs health checks (CPU, memory, environment, interfaces, logs) and live read-only commands, and handles enable / privileged EXEC automatically. The same read-only command allow-list and secret masking apply.

### 🔌 Telnet for legacy gear
Each device can now use **SSH (default)** or **Telnet**. Telnet is there for old equipment that has no SSH; the device form warns that it is not encrypted, so use it only on an isolated management network.

Also: the device vendor is validated on save, and the switch / router icons were redrawn to be clearer. Existing databases get the new `protocol` column automatically at startup; nothing to run by hand.

## Upgrade
From 2.1.x / 2.2.x on Linux: **user menu → Updates → Upgrade to 2.3.0**. Settings, database and backups are kept. Full changes in [CHANGELOG.md](https://github.com/justinthoms/network-config-manager/blob/main/CHANGELOG.md).
