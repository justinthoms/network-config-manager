## Added
- **FreeLLMAPI as an AI provider.** In **AI review → Add provider**, FreeLLMAPI now appears next to Gemini, OpenAI, Anthropic, Groq, Mistral, OpenRouter and Ollama. It is OpenAI-compatible, so you only enter two things: the address of your self-hosted FreeLLMAPI (for example `http://<server-ip>:3001/v1`) and the unified key (`freellmapi-…`) from its dashboard. Try the model `auto`.

FreeLLMAPI is a separate open-source project you run yourself; NCM does not bundle it and only talks to it over the network, exactly like any other provider.
