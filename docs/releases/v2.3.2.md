## Added
- **Google Drive: move older backups into the current folder.** If you renamed the Drive folder one or more times, older backups stayed in the old folders. The Cloud page now shows a **“Move N into …”** button next to the heads-up note; one click moves every NCM backup into your current folder (`<folder>/<device>`), so everything ends up in one place. It only touches files NCM created and deletes nothing.
